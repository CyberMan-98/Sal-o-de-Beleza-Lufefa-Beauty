Lufefa Beauty - Website

Este projeto é uma página de apresentação para um salão de beleza especializado em extensões e tratamentos capilares.

Desenvolvido com **HTML5** e **CSS3**, com foco em design moderno, responsividade e experiência do usuário.

Aprendizado com HTML e CSS

Este projeto faz parte do meu processo de aprendizagem de **desenvolvimento web front-end**. Ao construir este site, pude colocar em prática:

- Estruturação de conteúdo com HTML semântico
- Estilização com CSS moderno e organizado
- Layouts responsivos usando Flexbox e Grid
- Criação de seções como Hero, Sobre Nós, Serviços, Galeria, Localização e Contato
- Integração com WhatsApp para atendimento direto

Além de desenvolver a estética do site, também exercitei boas práticas de organização de código e adaptação para diferentes dispositivos (desktop, tablet e mobile).

Objetivo
O objetivo deste projeto é demonstrar habilidades práticas com HTML e CSS, criando uma landing page funcional e atrativa para pequenos negócios, como salões de beleza.

Tecnologias Utilizadas

- HTML5
- CSS3
- Responsividade com media queries
- Links externos (WhatsApp, redes sociais)
